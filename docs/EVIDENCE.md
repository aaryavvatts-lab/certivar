# Evidence map

Every quantitative claim in the paper is read from `results/paper_numbers.json` (written by `code/11_numbers.py`), from a
table generated by `code/12_tables.py`, or, where noted, from a file in `results/`. This table maps each claim to its
source. Section numbers refer to the paper; numbers given only in the supplement (Section S7) map to the same keys.
